## 2. Feature Cards (Core & Vertical Slices)

### Core Pipeline Orchestration, Dual-Mode Stop & Config (`Housekeeping.Core\Services\`)
- **What it does:** Coordinates the 8 execution modules, distinct FIFO `"Up Next"` pending queue (`PendingRuns`), dual-mode stop & graceful shutdown controls (`StopCurrentJob` advancing the active queue, `StopActiveRun` clearing `PendingRuns` & checkpoint, and `InitiateGracefulShutdownAbort` preserving `interrupted_run_checkpoint.json` & `PendingRuns` across upgrades/reboots), monotonic UTC scheduling (`LastScheduledRunUtc`), `<InstallRoot>\data` containment, and per-caller `{target}.{pid}.{guid:N}.tmp` atomic JSON persistence with 20-snapshot rollback history.
- **Entry Points:** [`PipelineOrchestratorService.cs`](Dev/Housekeeping.Core/Services/PipelineOrchestratorService.cs), [`PipelineOrchestratorService.CancellationAndShutdown.cs`](Dev/Housekeeping.Core/Services/PipelineOrchestratorService.CancellationAndShutdown.cs), [`ConfigService.cs`](Dev/Housekeeping.Core/Services/ConfigService.cs), [`ConfigService.AtomicIoAndMigrations.cs`](Dev/Housekeeping.Core/Services/ConfigService.AtomicIoAndMigrations.cs)
- **Verification Tests:** [`AuditV0112DataAndShutdownTests.cs`](Dev/Housekeeping.Tests/AuditV0112DataAndShutdownTests.cs), [`AuditV0112FleetDoctorCliTests.cs`](Dev/Housekeeping.Tests/AuditV0112FleetDoctorCliTests.cs), [`QueueDeduplicationRc9Tests.cs`](Dev/Housekeeping.Tests/QueueDeduplicationRc9Tests.cs), [`ServerAndOrchestratorTests.cs`](Dev/Housekeeping.Tests/ServerAndOrchestratorTests.cs)
- **Config / State Hooks:** Reads and persists `settings.json` (`Schema v4` + `[JsonExtensionData]`), `history.json`, `interrupted_run_checkpoint.json`, and `backups\config_snapshots\`.

### Resilience, Exclusive SMB Pre-Probe & Observability (`Housekeeping.Core\Services\`)
- **What it does:** Protects shared NAS targets with per-file and `pid`+`processStartTimeUtc` directory `.hklock` sentinels, commits `.partial` encodes via `TryProbeExclusiveAccess` (`FileShare.None`) without pre-deleting `finalOutputPath`, resumes `NtSuspendProcess`-paused child trees before cancellation kills, deduplicates repeated `[WARN]` / `[HH:mm:ss]` log prefixes across `10 MB × 5` `Housekeeping_Live.log` files, and writes filtered zero-PII JSON crash bundles (`crashes\`).
- **Entry Points:** [`NetworkSafetyService.cs`](Dev/Housekeeping.Core/Services/NetworkSafetyService.cs), [`NetworkSafetyService.DirectoryLocks.cs`](Dev/Housekeeping.Core/Services/NetworkSafetyService.DirectoryLocks.cs), [`PendingSwapService.cs`](Dev/Housekeeping.Core/Services/PendingSwapService.cs), [`ProcessRunnerService.cs`](Dev/Housekeeping.Core/Services/ProcessRunnerService.cs), [`TerminalLogBufferService.cs`](Dev/Housekeeping.Core/Services/TerminalLogBufferService.cs), [`CrashBundleService.cs`](Dev/Housekeeping.Core/Services/CrashBundleService.cs), [`CrashBundleExceptionFilter.cs`](Dev/Housekeeping.Core/Services/CrashBundleExceptionFilter.cs)
- **Verification Tests:** [`AuditV0112DataAndShutdownTests.cs`](Dev/Housekeeping.Tests/AuditV0112DataAndShutdownTests.cs), [`Nightly20261101AuditTests.cs`](Dev/Housekeeping.Tests/Nightly20261101AuditTests.cs)
- **Config / State Hooks:** Manages `pending_swaps.json`, `<LogDir>\Housekeeping_Live.log`, `<LogDir>\runs\`, `<LogDir>\crashes\`, and `<LogDir>\telemetry_heartbeat.json`.
